# SmartAlarm

Kotlin ve Jetpack Compose ile geliştirilen Android alarm uygulaması.

Bu depo şu anda yalnızca çalışan ilk uygulama iskeletini içerir; alarm özelliği henüz eklenmemiştir.

## Gereksinimler

- JDK 17
- Android SDK 35
- Gradle 8.11.1

## Derleme

```bash
gradle assembleDebug
```

Debug APK `app/build/outputs/apk/debug/app-debug.apk` yolunda oluşturulur.
